Architecture & Tooling

Tech Stack

The frontend frameworks, Supabase data layers, Gemini AI integrations, and deployment pipelines behind each application.

MIG Stock

Live ↗ GitHub ↗
  • ⚛️
    Frontend: React 18, TypeScript, Vite, and React Router.
  • 🎨
    Interface: Material UI with Emotion, responsive side and bottom navigation.
  • 🗄️
    Data: Supabase Postgres, email/password Auth, Row Level Security, and atomic stock and sales functions.
  • 🤖
    AI: Google Gemini powers natural-language questions through the app’s chat API.
  • 📊
    Documents and reports: Recharts, SheetJS, jsPDF, and html2canvas.
  • 📱
    Delivery: Installable PWA, deployed on Vercel.

Phoenix

Live ↗ GitHub ↗
  • ⚛️
    Frontend: React 19, TypeScript, Vite, and React Router.
  • 🎨
    Interface: Tailwind CSS, Radix UI primitives, Lucide icons, and responsive desktop/mobile layouts.
  • 💾
    Current data layer: A browser store keeps sessions, timers, customers, assets, and history after refresh.
  • ⏱️
    Session engine: Timers derive from saved start timestamps; billing applies the one-hour minimum and 30-minute increments.
  • 📄
    Documents: jsPDF and html2canvas are included for printable or shareable output.
  • 📱
    Delivery: Offline-capable PWA, deployed on Vercel.

Supabase Auth and database schema are prepared for a later cloud cutover, while the live UI runs instantaneously on the browser store.

Lalitamba

Live ↗ GitHub ↗
  • ⚛️
    Frontend: React, TypeScript, Vite, and React Router.
  • 🎨
    Interface: Tailwind CSS, shadcn/ui, custom stroke icons, and a phone-first PWA layout.
  • 🗄️
    Backend: Supabase Auth, Postgres, private receipt Storage, and Row Level Security.
  • 🤖
    OCR: A Supabase Edge Function sends receipt images to Gemini and returns structured fields for review.
  • 🔐
    Security: Receipt files stay private and the Gemini key remains inside the server-side function.
  • 📱
    Delivery: Installable PWA, hosted on Vercel.

Deposits

Live ↗ GitHub ↗
  • ⚛️
    Frontend: React, TypeScript, Vite, Material UI, and React Router.
  • 🗄️
    Backend: Supabase Postgres, shared-family Auth, and Row Level Security.
  • 🧮
    Ledger: Pure TypeScript calculates monthly payouts and break-even progress; money stays as integer paise.
  • 📆
    Due dates: Payout rows are generated when the app loads, avoiding a separate cron or serverless job.
  • 📤
    Backup: SheetJS exports all ledger tables to an Excel workbook.
  • 📱
    Delivery: Installable PWA with automatic Vercel deployments from GitHub.

Analytics uses lightweight custom progress bars rather than a heavy charting library.
